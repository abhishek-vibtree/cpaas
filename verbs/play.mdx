---
title: "<Play>"
description: "Play audio to the caller."
---

`<Play>` plays an audio file to the caller, then advances to the next verb.

```xml
<Response>
  <Play>welcome</Play>
  <Hangup/>
</Response>
```

## Supported today

<Check>Built-in audio files (Asterisk media names, e.g. `hello-world`, `vm-goodbye`).</Check>
<Check>Remote audio URLs — `<Play>https://.../file.mp3</Play>`.</Check>

For a built-in name, the value is the media name. Answering the caller and playback are handled automatically; the program advances when playback finishes.

### Remote audio URLs

A `<Play>` (or a `<Play>` nested inside `<Gather>`) with an `http(s)://` value is **fetched, transcoded, and cached** automatically: at webhook-fetch time OneML downloads the URL, converts it to a telephony WAV, caches it under Asterisk's sounds tree, and plays it. The first play of a given URL pays the download+transcode cost; later plays are served from cache.

<Note>
Common formats (MP3, WAV, …) are supported via ffmpeg. If a URL can't be fetched or transcoded, the `<Play>` is skipped and the program continues — it never fails the call.
</Note>

## Attributes

<ParamField path="loop" type="integer" default="1">
  Parsed. Repeat count for the audio.
</ParamField>
