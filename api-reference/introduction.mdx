The OneML REST API is a drop-in for the Twilio REST API: same base path, same HTTP Basic auth, JSON responses with snake_case fields.

## Base URL

```
https://cpaastokyo.oneinbox.ai
```

<Note>
Point your Twilio client's base URL here. The Twilio helper SDKs hardcode `api.twilio.com`, so use a base-URL/`edge`/custom-httpClient override, or call the endpoints with raw HTTP.
</Note>

## Authentication

HTTP Basic — `AccountSid` as username, `AuthToken` as password. See [Authentication](/authentication).

```bash
curl -u AC…:auth_token https://cpaastokyo.oneinbox.ai/2010-04-01/Accounts/AC….json
```

## Conventions

- Paths are prefixed `/2010-04-01/Accounts/{AccountSid}`.
- Request bodies are `application/x-www-form-urlencoded` (like Twilio).
- Responses are JSON. Resource fields use snake_case (`account_sid`, `call_sid`, …).
- An account may only access its own resources.
